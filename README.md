## Prompt

*Create an HTML form that uses jQuery to submit the results to a PHP function which uses a SQL query to insert the form results into a fictitious database table.*

## Installation

- Install PHP 8.x
- Ensure the `sqlite3` and `pdo_sqlite` modules are installed for your version of PHP (`$ php -m | grep sqlite`)
- Download project folder

## Serving the site

In your terminal: 
- CD into project directory
- start the server: `php -S localhost:8888`
